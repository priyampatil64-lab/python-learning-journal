## Notes

**What is Python?**
Python is a high-level, interpreted, general-purpose programming language known for its simple, readable syntax.

**Key features:**
- Easy to read and write
- Interpreted (no separate compile step)
- Dynamically typed (no need to declare variable types)
- Huge standard library and community support
- Cross-platform

**Variables & Data Types:**
Python has these common built-in data types: `int`, `float`, `str`, `bool`, `list`, `tuple`, `dict`, `set`.

**Type Conversion:**
Converting one data type to another, e.g. `int("5")` turns a string into an integer.

**Arithmetic Operators:**
`+` `-` `*` `/` `//` `%` `**`

**Comments:**
`#` for single-line comments, `'''triple quotes'''` for multi-line comments/docstrings.
